📝 Contact log template
When logging a non-converted guest in Mindbody, include the following:
  • Benefit(s) interested in — what drew them in (stress, sleep, recovery, detox, skin, etc.)
  • Membership/package they were interested in — tier discussed, if any
  • Reason they didn't purchase — too expensive, ClassPass user, needed to think, travels often, etc.
  • Notes — any additional detail to remember for the guest's follow-up or second visit
📖 How to pull the Attendance Analysis report
Follow these steps in Mindbody to generate the visits report for upload.
1. In Mindbody, go to Insights / Reports and open "Attendance Analysis"
2. Section 1 — Date range:
Use the "Quick date setting" dropdown and select Last 365 days
3. Section 2 — Service categories:
Click the dropdown, then under "IR Sauna Session" select IR Sauna Session
4. Section 3 — Analysis:
• "Analysis by" dropdown → select Guest
• Click Detail report
• In "Show clients with [x] or more visits," enter 1
5. Section 4: Click Go to run the report
6. Click Export to Excel (XLS) and save the file to your computer
7. Come back here and click "Upload report below" to import it

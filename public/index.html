How to use Suite Status

  • Default: Every suite starts as "Warming up" between sessions — no action needed
  • Tap "Ready" once a suite is fully prepped (cleaned, towels, preferences set)
  • Tap "Check-in at desk" for a first-timer or anyone who needs the front desk first (payment, waiver, etc.)
  • Add the guest's first name to personalize — and check "Moved" if you've moved them from a different suite
  • Early arrival? Tap "Skip to next session →" to jump that suite ahead to the upcoming appointment. Their name and status save against the next slot. Tap "← Back to current session" if you skipped by mistake.
  • No need to reset anything — every status, name, and "Moved" flag auto-clears 15 min before the next appointment
  • Need to close a suite? Tap "Close suite" at the bottom of the suite card. The card collapses and the lobby shows "Closed" instead of an appointment. Stays closed (even across days) until you tap "Reopen suite."
  • See a red error banner? Tap the same button again. If it keeps failing, hard refresh the page (Cmd + Shift + R).

🖥 Lobby screen for guests

This is the guest-facing display. Pull it up on the second monitor at the front desk so guests can see their suite status when they walk in.

To set it up each day:

1. Open the Lobby Screen shortcut from the desktop (the icon labeled with a P)

3. Press Cmd + Ctrl + F to make it fullscreen
4. That's it — leave it running. It updates automatically when you change a suite's status here.

📝 Contact log template
When logging a non-converted guest in Mindbody, include the following:
  • Benefit(s) interested in — what drew them in (stress, sleep, recovery, detox, skin, etc.)
  • Membership/package they were interested in — tier discussed, if any

📖 How to pull the Attendance Analysis report
Follow these steps in Mindbody to generate the visits report for upload.
1. In Mindbody, go to Insights / Reports and open "Attendance Analysis"
2. Section 1 — Date range:
Use the "Quick date setting" dropdown and select Last 365 days
3. Section 2 — Service categories:
Click the dropdown, then under "IR Sauna Session" select IR Sauna Session
4. Section 3 — Analysis:
• "Analysis by" dropdown → select Guest
• Click Detail report  ⚠ NOT "Summary"
• In "Show clients with [x] or more visits," enter 1
⚠ Common mistake: If you click "Summary" by accident, the file will have columns like "Visiting Clients" and "Total Clients" — those won't work. The Detail report has a row for each member with a "Signed-In Visits" column.
5. Section 4: Click Go to run the report
6. Click Export to Excel (XLS) and save the file to your computer
7. Come back here and click "Upload report below" to import it
📖 How to pull the New Members report
Follow these steps in Mindbody to export new members for upload.
1. Log in to Mindbody
2. Go to Insights / Reports
3. Click on the report "New Members"
4. Leave at default settings for last 30 days
5. Press Generate
6. Click Export to Excel (XLS) and save the file to your computer
7. Come back here and click "Sync member roster below" to import it
💡 What we compare: Each name in this report is checked against the New Guest tracker. Any members who aren't in the tracker yet will be listed so you can quickly add them.
⏱ Date cutoff: Only members who joined on or after 4/22/2026 (the day the tracker launched) are flagged as missing. Earlier members are silently ignored as historical.
🛑 How to deactivate active sessions in Mindbody
Use these steps when a member's payment has been declined and you need to stop them from booking until the charge is resolved.
1. Go to the client's Mindbody profile
2. Click on "Account details"
3. Review current line items under the "Active" section at the top
4. Click the three dots next to each item
5. Click "Edit"
6. Uncheck the box next to "Active pricing option"
7. Save changes — repeat for any other active items
💡 Once payment is recovered, you can come back here to re-activate the same items by re-checking the "Active pricing option" box.

Daily Hub — your day-to-day shift tools: shift notes, announcements, today's tasks, events & promos, learning library, monthly performance.

💳 Declined Payment Recovery

When a member's card declines, log it as a Declined Payment from the Membership Changes form. You'll need to:

  • Note the reason (insufficient funds, fraud, expired card, etc.)
  • Deactivate active sessions in Mindbody (instructions popup linked from form)
  • Add a Mindbody contact log noting the decline + what was deactivated
  • Initial outreach to the member with built-in scripts

Logging the request automatically starts a 14-day recovery flow visible in Nurture & Reactivations:

  • Day 0 — initial outreach (already done at logging)
  • Day 5 — first follow-up touchpoint
  • Day 10 — final follow-up touchpoint with cancellation warning
  • Day 14 — appears on Mohogany's dashboard alert as ready to convert to a termination

If the member resolves the payment, mark the nurture complete to stop the timer.

✅ Team Lead Tasks

Mohogany's home base for recurring responsibilities. Three sections:

  • 🌅 Daily Reminders — auto-generated. Upload prompts, declined-payment 14-day deadlines, pending member reviews. Each row clicks straight to the action. Disappears when done.
  • 📅 This Week — full master checklist resets every Sunday at midnight ET. Mohogany completes in any order, on whichever days she's working. Examples: Pull Last Visit Report, Care calls, Inventory, B2B management, Staff coaching, Audit previous week's first visits, etc.
  • 🗓️ This Month — resets on the 1st of each month. Examples: Update backroom whiteboard.

Click the checkbox to mark complete. Click 📋 View instructions on any task to see step-by-step how-to (with sub-steps, target days, notes, and examples where applicable).

Days off? No problem. Mohogany just doesn't check anything off — Sunday's reset starts fresh regardless.
